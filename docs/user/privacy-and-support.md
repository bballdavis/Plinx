# Privacy and support

## Privacy

Plinx does not collect analytics, crash reports, or usage telemetry. It stores
the settings needed for the app to work on the device and communicates directly
with Plex and any parent-configured local service.

Read the full [Privacy Policy](privacy-policy.md)
for details about local storage, Plex communication, children and families, and
retention.

## Support

For a reproducible issue or feature request, use the
[Plinx issue tracker](https://github.com/bballdavis/Plinx/issues). Do not include
Plex tokens, passwords, personal server addresses, or other account secrets in
an issue.
