## Updating Strimr

The exact commit is intentional. Plinx compiles selected Strimr source directly
and relies on verified seams, so an upstream update is a manual compatibility
operation rather than an automatic branch-head update.

Follow the [branch pairing guide](../development/branch-pairing.md) when you
prepare, test, promote, or roll back a Strimr candidate. Update the dependency
configuration only after the candidate's seam checks, relevant tests, and
paired builds have passed.
