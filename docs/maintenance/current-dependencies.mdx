# Current dependencies

This page is generated during the documentation build from the repository's
machine-readable configuration. It is the current status view, not a second
source of truth.

<DependencyStatus />

## What these values mean

- **Absorbed Strimr base** is the upstream `wunax/strimr` commit whose source
  Plinx absorbed into `PlinxApp/Core` and `PlinxApp/Platform`. It is the start
  of every upstream review range. It is not a build input: the app compiles
  only what is in this repository.
- **Swift packages** are fetched as source by Swift Package Manager at the
  exact revision or version recorded in `PlinxApp/project.yml`. CI and release
  builds never follow a branch head.
- **Xcode** is the toolchain the project, CI and Xcode Cloud are set up for.

## Changing a dependency

Change a Swift package pin or the Xcode version in `PlinxApp/project.yml`,
regenerate the Xcode project, and run the builds and tests in the
[testing guide](../development/testing.md). Check the package's license against
the [open-source compliance checklist](../release/open-source-compliance.md)
before the change ships.

Upstream Strimr changes arrive by hand-porting, not by moving a pin. Follow
[upstream Strimr provenance](upstream-strimr.md) to review and port them.
